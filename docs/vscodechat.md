VS Code의 Copilot Chat은 단순한 Q\&A를 넘어, 사용자의 의도에 맞게 작동 방식을 바꿀 수 있는 강력한 기능들을 제공합니다. 말씀하신 **Agent (`@`)**, **Ask (`/ask`)**, \*\*Edit (`/edit` 및 인라인)\*\*는 Copilot Chat을 200% 활용하기 위한 핵심 기능입니다.

각 기능이 무엇이며 언제 사용해야 하는지 명확하게 알려드릴게요.

-----

### 1\. Agents (`@`) : "전문가 호출" 모드 👩‍⚕️👨‍💻

**"이 분야 전문가에게 물어볼게\!"**

Agent는 Copilot의 '전문가'입니다. `@` 기호를 사용하여 Copilot이 **어떤 맥락(Context)에 집중**해야 할지 지정해 줍니다. 그냥 질문하는 것보다 훨씬 더 정확하고 맥락에 맞는 답변을 줍니다.

  * **사용 방법:** 채팅창에 `@`를 입력하면 사용 가능한 Agent 목록이 나타납니다.

#### 핵심 Agents:

  * `@workspace` (가장 중요 ⭐)
      * **역할:** 내 프로젝트 **전체 코드**를 참조하는 전문가.
      * **언제 사용하나요?**
          * "내 `UserService` 클래스와 `UserDTO` 파일을 참고해서 `UserController` 코드 좀 짜줘."
          * "프로젝트 전체에서 'API\_KEY'가 어디에 하드코딩되어 있는지 찾아줘."
          * "내 프로젝트의 코딩 스타일을 분석해서 이 파일에 적용해 줘."
  * `@vscode`
      * **역할:** VS Code **에디터 기능**을 조작하는 전문가.
      * **언제 사용하나요?**
          * "키보드 단축키 설정 파일 열어줘."
          * "내가 선택한 코드에 'try...catch' 스니펫(조각) 적용해 줘."
          * "현재 테마를 'Dark+'로 변경해 줘."
  * `@terminal`
      * **역할:** **터미널 명령어** 전문가.
      * **언제 사용하나요?**
          * "현재 폴더의 `node_modules` 폴더 용량만 알려주는 셸 명령어 알려줘."
          * "방금 `git commit`한 거 취소하는 명령어 뭐야?"
  * `@github` (GitHub Enterprise 사용자)
      * **역할:** 연결된 GitHub 저장소의 이슈(Issue), PR 등을 참조합니다.

### 2\. Ask (`/ask`) : "질문/학습" 모드 ❓

**"이건 그냥 궁금한데..."**

`Ask`는 가장 기본적이고 일반적인 **Q\&A 모드**입니다. 현재 내 코드나 프로젝트와 *직접적인 관련이 없는* 일반적인 지식, 개념, 코드 예제를 물어볼 때 유용합니다.

  * **사용 방법:**
    1.  채팅창에 그냥 질문을 입력합니다. (이것이 기본 모드입니다.)
    2.  명시적으로 `/ask`를 입력하고 질문을 시작할 수도 있습니다.
  * **특징:**
      * Agent와 달리, `@workspace`를 지정하지 않으면 현재 열린 파일이나 프로젝트 전체를 깊게 분석하지 않을 수 있습니다.
      * 주로 Copilot의 일반적인 코딩 지식 베이스를 활용합니다.
  * **언제 사용하나요?**
      * "자바스크립트에서 'Promise.all'과 'Promise.race'의 차이점이 뭐야?"
      * "Python으로 간단한 웹 스크래퍼 예제 코드 만들어줘."
      * "React의 'useEffect' 훅에 대해 설명해 줘."

### 3\. Edit (인라인 수정) : "코드 직접 수정" 모드  surgically ✍️

**"이 코드, 이렇게 고쳐줘\!"**

이것은 Copilot Chat의 **생산성을 극대화하는 핵심 기능**입니다. 채팅창에서 코드를 복사/붙여넣기 할 필요 없이, **에디터에서 바로 코드를 수정**하도록 지시합니다.

  * **사용 방법:**
    1.  수정하고 싶은 코드 블록을 \*\*마우스로 드래그(선택)\*\*합니다.
    2.  **`Cmd + I`** (Mac) 또는 **`Ctrl + I`** (Windows) 키를 누릅니다.
    3.  코드 위에 작은 **인라인(Inline) 채팅창**이 뜹니다.
    4.  거기에 원하는 수정 사항을 입력하고 `Enter`를 누릅니다.
  * **채팅창에서 `/edit` 사용법:**
      * 채팅 사이드바에서 `/edit`을 입력하고 지시 사항을 적으면, Copilot이 "어떤 코드를 수정할까요?"라고 되묻거나 현재 활성화된 파일을 기준으로 작업합니다.
      * 하지만 **`Ctrl+I` 인라인 방식이 100배 더 직관적이고 빠릅니다.**
  * **언제 사용하나요?**
      * (함수를 선택하고) "이 함수에 `try...catch` 예외 처리 추가해 줘."
      * (코드를 선택하고) "이 `for`문을 `map` 함수로 리팩토링해 줘."
      * (코드를 선택하고) "여기에 JSDoc 주석 달아줘."
      * (코드를 선택하고) "이 코드 더 읽기 쉽게 변수명 좀 바꿔줘."

결과물은 기존 코드를 대체하는 **Diff(변경 사항) 미리보기**로 표시되며, [Accept] 또는 [Discard] 버튼으로 쉽게 적용할 수 있습니다.

### 💡 요약 및 추천 사용법

| 기능 | 핵심 | 사용 방법 | 추천 상황 |
| :--- | :--- | :--- | :--- |
| **Agents (`@`)** | **맥락 지정** (전문가 호출) | `@workspace` "프로젝트 참고해서..."<br> `@terminal` "명령어..." | 프로젝트 전반에 걸친 복잡한 코드 생성, 파일 검색 |
| **Ask (`/ask`)** | **일반 질문** (개념, 예제) | 채팅창에 그냥 질문하기 | 특정 개념 공부, 간단한 코드 스니펫 생성 |
| **Edit (인라인)** | **코드 즉시 수정** (리팩토링) | 코드 선택 + `Ctrl`/`Cmd` + `I` | 기존 코드에 주석 추가, 버그 수정, 코드 개선 |

**가장 효율적인 워크플로우:**

1.  새로운 기능 구현은 \*\*`@workspace`\*\*를 사용해 프로젝트 맥락에 맞게 요청합니다.
2.  개념이 헷갈릴 땐 **`/ask`** (그냥 질문)로 빠르게 학습합니다.
3.  기존 코드를 다듬거나 버그를 잡을 땐 \*\*`Ctrl+I` (인라인 Edit)\*\*를 사용해 즉시 수정합니다.
